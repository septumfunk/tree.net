# Tree.Net
This is an implementation of the unix tree command in C# 15 (dotnet 11.0).
This version of dotnet released TODAY! And it has UNIONS!! 
I actually got so excited that I wrote the entire program in one go, forgetting
to commit as I was writing, so I might get knocked for that.

## Usage
You will need the [dotnet 11.0 sdk](https://dotnet.microsoft.com/en-us/download/dotnet/11.0) installed to build this program.
```
tree <dir>
```
